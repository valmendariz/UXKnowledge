# Terminology Eval Cases

Use this area for evaluation scenarios that verify that AI-generated UX language aligns with approved glossary entries and standards.

## Typical scenarios

- consistent names for states or actions
- approved labels versus informal alternatives
- error text alignment with glossary entries
- domain wording decisions

## Guidance

A terminology case should clearly identify the approved term and the prohibited alternative, while keeping the repository free of invented product terminology.
