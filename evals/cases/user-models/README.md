# User Model Eval Cases

Use this area for evaluation scenarios that test whether AI relies on user models and assumptions without inventing unsupported personas or behaviors.

## Typical scenarios

- making assumptions about unfamiliar users
- integrating observed user needs into design
- distinguishing explicit evidence from inferred behavior

## Guidance

Cases should require the model to remain evidence-based and to state uncertainty when user model assumptions are weak or missing.
