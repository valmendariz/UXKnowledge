# Interaction Pattern Eval Cases

Use this area for evaluation cases that test interaction-pattern knowledge and application.

## Typical scenarios

- error recovery flows
- empty states
- loading states
- confirmation and destructive actions
- multi-step form progress

## Guidance

Each case should make it explicit whether the AI is expected to use an established pattern, a standard, or an evidence-backed design decision.
