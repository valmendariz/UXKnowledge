# Research Grounding Eval Cases

Use this area for evaluation cases that check whether AI reasoning is grounded in relevant research, standards, and evidence.

## Typical scenarios

- using evidence appropriately
- distinguishing a finding from an interpretation
- stating when evidence is missing
- not presenting an inference as a fact

## Guidance

A good research-grounding case should test traceability, uncertainty handling, and the ability to say when knowledge is insufficient.
