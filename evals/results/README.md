# Evaluation Results

This folder stores outcomes from evaluation runs.

## Purpose

The results area helps teams understand whether repository knowledge is being used effectively, where gaps remain, and which issues need follow-up.

## What to record

- the eval case identifier
- the date and context of the run
- pass/fail or partial status
- the key failure mode
- whether the issue is a knowledge issue, retrieval issue, or reasoning issue
- recommended follow-up action
