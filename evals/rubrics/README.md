# Evaluation Rubrics

This folder holds reusable evaluation dimensions for testing whether repository knowledge is applied properly.

## Example dimensions

- knowledge retrieval
- UX rule adherence
- terminology accuracy
- research grounding
- pattern consistency
- unsupported inference
- accessibility considerations
- explanation and traceability

## Scoring model

Prefer a simple criterion-level scale:

- 0 = not demonstrated
- 1 = partially demonstrated
- 2 = demonstrated

Where an explicit pass/fail is more appropriate, use that instead.

## Purpose

The rubric should help distinguish whether the issue is a knowledge gap, retrieval failure, or a reasoning problem.
