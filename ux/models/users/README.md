# User Models

This directory is reserved for explicit user models, user group assumptions, and evidence-backed interpretations of user goals and behavior.

## Purpose

User models help the team reason about who is using the product and what needs, constraints, or behaviors matter most. They should remain grounded in evidence and clearly labeled when they are interpretive rather than validated fact.

## Rules

- Avoid inventing personas without evidence.
- Distinguish users as observed, synthesized, or inferred.
- Connect the model to its supporting evidence or research.
- Keep the model from being mistaken for a product rule or active standard.
