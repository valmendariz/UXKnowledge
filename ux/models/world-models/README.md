# World and Domain Models

This directory holds models of domains, systems, workflows, and relationships that shape product and UX decisions.

## Purpose

World models help teams understand context: how systems interact, how work unfolds, and which constraints matter to the user experience. They are useful for reasoning, but they should not be treated as product rules unless reviewed and validated.

## Rules

- Ground context in evidence where possible.
- Separate explicit assumptions from validated understanding.
- Keep the model aligned with research and product context.
- Do not treat a world model as a user-facing standard by itself.
