# User and World Models

This folder holds models that help teams reason about users, their goals, and the systems or domains they operate in. Models are useful but must remain distinguishable from validated standards and product-specific rules.

## Structure

- [users/](./users): user model documents and assumptions grounded in evidence.
- [world-models/](./world-models): domain and system relationship models that help explain context and constraints.

## Rules

- Models should be grounded in research, observed behavior, or explicit assumptions.
- A model is not automatically a UX rule.
- Avoid inventing personas or user archetypes without evidence.
- When a model is uncertain or unvalidated, say so explicitly.
