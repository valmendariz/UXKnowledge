# UX References

This folder is for supporting references that inform the repository but are not themselves the authoritative UX guidance layer.

## Purpose

Use this area for:

- external design guidelines
- internal process references
- standards documents
- research summaries from external sources
- curated reading lists or annotated references

## Rules

- References should be organized in a way that helps humans and AI locate the right source quickly.
- External references should be traceable and cited properly.
- Do not treat a reference as equal to approved internal guidance.
- Use this folder for support, not for storing duplicate knowledge that belongs in standards or patterns.
