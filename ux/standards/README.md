# UX Standards

This folder contains explicit UX standards that are intended to guide product experience decisions and AI-generated design work.

## Purpose

Standards represent the most authoritative, review-ready guidance in the repository. They should be specific, testable where possible, and grounded in evidence or a documented decision.

## Rules

- A standard should be clear about when it applies.
- Standards may reference established patterns and research, but they should not duplicate them without reason.
- If a standard is replaced or deprecated, its status must be updated and cross-links reviewed.
- A standard should be reviewable through Git history, provenance, and related evidence.

## Typical content

- interaction rules
- accessibility expectations
- terminology preferences
- error-handling rules
- content and communication guidance
