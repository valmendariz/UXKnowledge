# Structured UX Knowledge

This directory is the home for structured UX knowledge. It is organized by knowledge type so the repository can support both human review and AI retrieval.

## Directory map

- [research/](./research/README.md): research findings, summaries, and evidence syntheses.
- [standards/](./standards/README.md): validated or review-ready UX standards.
- [patterns/](./patterns/README.md): reusable interaction patterns and approved usage guidance.
- [models/](./models/README.md): user models and world/domain models.
- [glossary/](./glossary/README.md): controlled terminology and definitions.
- [references/](./references/README.md): supporting references and curated external or internal material.

## Content rules

- Keep files focused and specific.
- Prefer a single source of truth.
- Maintain clear provenance and links to source evidence.
- Use metadata consistently for status and evidence level.
- Avoid duplicating guidance across files.

## Knowledge hierarchy within this area

The highest-value guidance should live in standards and reviewed patterns. Research and models provide evidence and contextual understanding but do not automatically become rules.
