# UX Glossary

This folder holds controlled terminology used to keep product language consistent across design, engineering, and AI-assisted generation.

## Purpose

The glossary is not a general dictionary. It should contain terms that matter to the organization’s UX language and decision-making.

## Rules

- Prefer approved terms over informal equivalents.
- When an approved term differs from common usage, document the intended meaning.
- Do not add glossary entries for terms without clear organizational value.
- Keep terminology linked to relevant standards or references when appropriate.
