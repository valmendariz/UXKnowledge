# Governance

This section defines how the repository is maintained, reviewed, and trusted.

## Core documents

- [knowledge-lifecycle.md](./knowledge-lifecycle.md): how knowledge moves through states.
- [review-policy.md](./review-policy.md): review expectations and timing.
- [ownership.md](./ownership.md): who owns the knowledge area and review authority.
- [decisions/](./decisions): decision records for significant UX decisions.
- [templates/](./templates): reusable templates for operating the system.

## Principles

- Prefer a single source of truth.
- Keep provenance visible.
- Make uncertainty explicit.
- Keep governance lightweight but meaningful.
- Treat intake material as evidence, not approved guidance.

## Governance goals

This repository should help the team:

- understand what is authoritative
- know what evidence supports a decision
- identify stale or unreviewed knowledge
- maintain a healthy AI context layer
- operate the system without creating excessive bureaucracy
