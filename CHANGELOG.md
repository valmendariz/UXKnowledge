# Changelog

## 0.1.0

Date: 2026-09-28

### Added

- Initial repository structure for a governed UX knowledge system.
- Human-facing repository overview and contributor guidance.
- AI-oriented UX knowledge entry point and repository contract.
- Intake lifecycle and non-authoritative source handling.
- Governance documentation for review policy, lifecycle, metadata, and ownership.
- Audit framework and audit templates.
- Evaluation framework and reusable case template.
- Agent instructions for repository-aware UX work.
- Template library for standards, patterns, glossary, models, decisions, audits, and evals.

### Notes

This repository intentionally contains no product-specific guidance or invented user models. It establishes the structure, process, and templates needed for real organizational knowledge to be added safely.
